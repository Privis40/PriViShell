## What It Does

PriViShell is a reverse shell payload generator built for penetration testers, red teamers, and security researchers operating in **authorized environments**. It generates clean, ready-to-use payloads across multiple platforms and formats — saving time during authorized post-exploitation and CTF exercises.

The tool does **not** connect to any target system itself. It generates payload strings that the operator deploys manually within the scope of an authorized engagement.

## Payload Notes

**Bash (Base64 Encoded)**
Standard `/dev/tcp` bash reverse shell, Base64-encoded to evade basic pattern matching. Run on the target: `echo <b64> | base64 -d | bash`

**Python3 PTY Spawn**
Creates a fully interactive PTY using Python's `socket` and `pty` modules. Useful when bash `/dev/tcp` is unavailable or restricted.

**PowerShell Standard**
Full bidirectional PowerShell shell over TCP. Works on Windows without any evasion — suitable for environments where AV/AMSI is disabled or bypassed at the engagement level.

**PowerShell + AMSI Bypass**
Prepends an `amsiInitFailed` reflection bypass before the shell payload. This technique is publicly documented in red team literature. **Intended for authorized lab use and AMSI defence testing only.**

## Listener Setup

On your attacking machine before deploying any payload:

```bash
nc -lvnp <LPORT>
```

Or with rlwrap for a more stable shell:

```bash
rlwrap nc -lvnp <LPORT>
```
